# VoIPCalc-Core — VOIP 费率计算引擎规格说明书

## 1. 产品定位与愿景

VoIPCalc-Core 是跨境 VOIP 话务系统的核心计价引擎。它的职责非常纯粹：给定一通电话的基本信息（主叫号码、被叫号码、拨打时间），结合目的地国家、客户身份和通话时段，计算出最终每分钟费率。整个系统追求的是**正确性**、**纯粹性**和**可追溯性**——每一个费率决策都清晰可查、可独立验证。

## 2. 领域模型

### 2.1 通用语言

| 术语 | 含义 |
|------|------|
| `CallContext` | 费率计算的输入载体，包含：主叫号码、被叫号码、客户类型、通话开始时间 |
| `PhoneNumber` | 电话号码值对象，封装了原始号码及其对应的国家代码 |
| `CustomerType` | 客户类型枚举：`VIP`（海外留学生/华人卡用户）、`NORMAL`（普通用户） |
| `CountryCode` | 国家代码枚举：`CN`（+86）、`US`（+1）、`OTHER`（兜底默认值） |
| `RateResult` | 费率计算结果，包含最终单价和完整的计算过程审计链 |
| `BaseRatePolicyService` | 基础费率策略：根据被叫号码的国家代码返回对应基础费率 |
| `CustomerDiscountPolicyService` | 客户折扣策略：根据客户身份返回折扣系数 |
| `NightOffPeakPolicyService` | 夜间低谷策略：根据通话时间判断是否享受夜间减免 |
| `RateCalculationEngine` | 费率计算引擎：编排三大策略，计算最终费率的核心领域服务 |

### 2.2 业务规则

#### 规则 1 — 基础费率（按目的地国家）

| 国家代码 | 费率（元/分钟） |
|---|---|
| +86（中国） | ¥0.10 |
| +1（美国） | ¥0.05 |
| 其他国家/地区 | ¥0.50（兜底） |

#### 规则 2 — 客户身份折扣

| 客户类型 | 折扣系数 |
|---|---|
| VIP（海外留学生/华人卡） | 0.9（打九折） |
| NORMAL（普通用户） | 1.0（不打折） |

#### 规则 3 — 夜间低谷福利

- 适用时段：当日 23:00 至次日 05:00（以通话发起时间为准）
- 减免金额：每分钟直接减 ¥0.02
- 下限保护：减免后费率若为负数，按 ¥0.00 计算（不倒贴钱）

### 2.3 计算公式

```
基础费率 = 根据被叫号码查CountryCode得到对应费率
折扣后费率 = 基础费率 × 客户折扣系数
最终费率 = max(0, 折扣后费率 − 夜间减免额)
```

## 4. API 设计

### GET /api/rate

**请求参数（Query String）**

| 参数名 | 类型 | 必填 | 示例 |
|---|---|---|---|
| `callerNumber` | string | 是 | `+8613812345678` |
| `calleeNumber` | string | 是 | `+14155551234` |
| `customerType` | string | 是 | `VIP` 或 `NORMAL` |
| `callStartTime` | ISO-8601 格式 | 是 | `2024-06-06T02:30:00` |

**成功响应（200 OK）**

```json
{
  "baseRate": 0.05,
  "discountFactor": 0.9,
  "offPeakReduction": 0.02,
  "finalRate": 0.025,
  "currency": "CNY",
  "breakdown": {
    "countryCode": "+1",
    "countryName": "美国",
    "customerType": "VIP",
    "isNightOffPeak": true,
    "rateZone": "NIGHT_OFF_PEAK"
  }
}
```

**错误响应**

| 状态码 | 原因 |
|---|---|
| 400 | 参数缺失或格式错误 |
| 500 | 内部计算异常 |

## 5. 验收标准

- [ ] 中国(+86)、普通用户、白天通话 → ¥0.10/分钟
- [ ] 美国(+1)、VIP用户、白天通话 → ¥0.045/分钟
- [ ] 美国(+1)、VIP用户、夜间凌晨02:30 → ¥0.025/分钟
- [ ] 美国(+1)、普通用户、夜间23:45 → ¥0.03/分钟
- [ ] 其他国家、普通用户、夜间 → ¥0.48/分钟
- [ ] 其他国家、VIP用户、白天（基础¥0.50打九折）→ ¥0.45/分钟
- [ ] 所有策略服务均可独立测试，不依赖 Spring 容器
- [ ] 所有领域服务均无状态、无副作用

- **前端**：Vue 3（Composition API）、Vite、Axios
